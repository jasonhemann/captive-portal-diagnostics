# Security policy

## Supported versions

Security fixes are made on the latest released version.

## Reporting a vulnerability

Please do not include packet captures, credentials, session cookies, private
network addresses, or portal tokens in a public issue. Use GitHub's private
security-advisory reporting flow for the repository once it is published, or
contact the maintainer privately.

Include a minimal reproduction, the operating system and Python version, and a
redacted description of the observed behavior. The `captive-portal-safe-review`
command can produce a reduced report suitable for an initial discussion.
